# T6 riwayat, review dan ekspor implementation plan

**Goal:** Petugas/reviewer dapat mencari inspeksi tersimpan (filter tanggal/area/status), membuka detail beserta foto, mencatat review per temuan (Belum selesai/Ditutup) dengan penanganan konflik revisi, dan mengekspor CSV/GeoJSON yang aman dibuka di Excel/QGIS.

**Architecture:** Tiga aksi gateway baru membaca/menulis tab `Inspections` yang sama: `listInspections` (ringkasan + filter, tanpa blob), `getInspection` (detail + metadata foto, tanpa byte), `reviewInspection` (revisi baru berversi dengan `reviewId` idempoten). Review disimpan additif di kolom baru `review_json` (Z; skema sederhana 16) sebagai riwayat array terbatas. Ekspor dibangun di browser dari data daftar (murni, tanpa aksi server). Foto tetap hanya lewat pasangan ID inspeksi+foto yang sudah ada.

**Tech stack:** Next.js/React/TypeScript dan Apps Script yang ada; tanpa dependency baru.

**Spec:** docs/plan.md §3 (Riwayat/Review/Ekspor), §5 (layar Riwayat/Detail), §8 (metadata), §12 (kontrak action), §13 T6; keputusan akses tanpa login; permintaan pengguna 10 Oktober (foto penutupan ditunda).

## Global constraints

- T6 saja; T6 tidak menambah login/aktivasi, tidak mengubah izin Drive/foto, tidak menyentuh T7/Production.
- Foto penutupan ditunda atas keputusan pengguna; jangan mengubah alur/manifest T4.
- Skema additif: kolom `review_json` ditambahkan di kanan; header/baris lama tidak ditulis ulang. Header staging 25 → 26 kolom (Z), sederhana 15 → 16.
- Review hanya untuk record `submitted`; konflik versi = `VERSION_CONFLICT` (409), retry dengan `reviewId` sama = replay idempoten.
- CSV: lindungi sel berawalan `= + - @`/tab dari formula injection dan kutip RFC4180. GeoJSON: `[longitude, latitude]` WGS84; tanpa lokasi = geometry `null`.
- Tanpa aktivasi: `listInspections`/`getInspection` terbuka bagi pemegang URL; jangan pernah mengembalikan byte foto atau ID Drive dari aksi ini.
- Gateway build naik ke `2026-10-10.2`; deploy dua file (`gateway`, `storage`) lewat prosedur README setelah checks lulus.

## Review focus

- Filter tidak boleh melempar pada baris lama/misaligned; baris tanpa UUID dihitung `skipped`, bukan dihapus/ditulis ulang.
- Review dua tab/reviewer: versi lama ditolak tanpa menimpa; replay `reviewId` tidak menggandakan revisi.
- Ekspor tidak boleh menghasilkan `#ERROR!`/rumus saat dibuka di Excel; `[lon,lat]` benar untuk QGIS.
- Detail tidak membocorkan byte foto; baca foto tetap lewat pasangan ID.
